# 🌎 Import Export E-Commerce Website

A professional and responsive static website designed for an import-export business.  
It showcases products, allows customers to view details, choose size and color options, and place orders via an integrated Google Form with payment QR support.

---

## ✨ Features

- 🎥 **Animated video background** on the home page for a premium look  
- 🛒 **Products page** listing all available import/export goods  
- 🎨 **Color and size selection** for each product  
- 💳 **Buy Now integration** — opens Google Form for order submission with UTR and payment screenshot upload  
- 📞 **Contact Us page** with a working contact form  
- 📱 Fully **responsive design** for desktop and mobile  
- ⚡ Built with pure **HTML, CSS, and JavaScript** (no frameworks)

## 🧠 How It Works

1. The **Home Page** welcomes visitors with a looping video background and navigation links.  
2. The **Products Page** displays your items, where users can view details, select options, and click “Buy Now.”  
3. On clicking **Buy Now**, users are redirected to a **Google Form** with payment QR and fields for UTR & screenshot upload.  
4. Orders are collected directly in your **Google Drive** via the form.  
5. The **Contact Us** page allows users to send direct inquiries.
